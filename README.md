# temp-monitor

Temp Monitor System (C++ Embedded Simulation)

Config-driven C++ temp monitor with simulated sensor/GPIO, state machine (INIT→IDLE→MONITORING→ALARM→SHUTDOWN), and multithreading. Ideal for embedded logic prototyping, threshold alerts, retry/backoff, and unit-testable hardware behavior.

Features:
- Sensor simulation
- State machine
- Multithreading
- GPIO simulation
- Config-driven system
